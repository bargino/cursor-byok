# Cursor BYOK 1.0.4 — Account plugins and pools

## Added

- WorkBuddy China/Global login, model discovery, streaming tools, token renewal, credit/package queries,
  credential import/export and manual China personal-account check-in.
- Qoder China/Global PKCE login, COSY-signed native model calls, model discovery and quota buckets.
- TeleAgent (China Telecom) isolated official login, signed model calls and points queries. Browser
  login requires the official TeleAgent client to be installed and started once. Complete credential
  imports are also supported.
- Kiro AWS Builder ID login in us-east-1, regional OAuth/API Key imports, binary EventStream model
  responses and Credits. EU Builder ID browser authorization returned invalid_request during the
  endpoint check, so eu-central-1 uses credential/API Key import.
- Official Qoder, TeleAgent and Kiro logos with source URLs and SHA-256 provenance files.

## Fixed

- Account-list read/merge/write operations share one persistence lock. Concurrent login, refresh and
  removal no longer replace the complete list with an older snapshot.
- Account selection rotates ready accounts and retries another account only before output starts.
- Account leases serialize token changes for one account while other accounts proceed independently.
- Codex, Google and Grok identity tests cover multiple accounts and stable identity across renewal.
- Closing a login panel cancels its session; TeleAgent closes only its own isolated browser window.
- Credential refresh responses and sensitive authentication headers are excluded from model call logs.

## Packages

The **Build desktop installers** workflow produces Windows x64 NSIS/MSI/portable ZIP, Linux x64
AppImage/DEB/RPM/binary archive, and macOS Intel/Apple Silicon DMG/application archives. Each Actions
artifact includes a commit/version manifest and SHA256SUMS.txt. Download the installer matching your
platform after the workflow has completed successfully.

## Validation boundaries

Protocol tests use simulated HTTP, SSE and AWS binary frames. The native TeleAgent callback also has
an opt-in test using a real isolated Chrome instance with intercepted fixture responses. Reachability
checks covered official login endpoints and anonymous US Builder ID device authorization. Real account
authorization, model billing, renewal and actual balance queries still require live validation.
