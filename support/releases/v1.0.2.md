# Cursor BYOK v1.0.2

First packaged release of the community fork maintained at [bargino/cursor-byok](https://github.com/bargino/cursor-byok), based on the MIT-licensed [leookun/cursor-byok](https://github.com/leookun/cursor-byok). Thanks to the original author and contributors.

## 下载哪个文件 / Downloads

| 系统 | 安装版 | 便携版或应用压缩包 |
| --- | --- | --- |
| Windows x64 | `*_x64-setup.exe` 或 `*_x64_en-US.msi` | `cursor-byok-1.0.2-windows-amd64.zip` |
| macOS Apple Silicon（M 系列） | `*_aarch64.dmg` | `*_aarch64.app.tar.gz` |
| macOS Intel | `*_x64.dmg` | `*_x64.app.tar.gz` |
| Linux x64 | `*_amd64.deb` 或 `*.x86_64.rpm` | `*_amd64.AppImage` 或 `cursor-byok-1.0.2-linux-amd64.tar.gz` |

The Assets section also contains updater archives and signatures, three update manifests, and `SHA256SUMS.txt`. `.sig` and `.json` files are used by the updater and are not installers.

## Changes

- Support Cursor's binary BidiAppend payloads and reject ambiguous binary/hex requests.
- Add RunInference streaming, tool round trips, reasoning-state replay, heartbeats, and cancellation.
- Keep BYOK turn-classification reports local and configure the relevant bootstrap gates.
- Handle subagent messages with omitted IDs while preserving retry and checkpoint identity.
- Recognize additional context-overflow responses for compaction and retry.
- Configure this fork's independent updater signing key and update endpoints.
- Update frontend dependencies to address the previous source publication's npm audit findings.

## 从原上游切换 / Switching from upstream

请先完全退出 Cursor 和 Cursor BYOK，并备份模型配置与数据目录 `~/.cursor-byok-v3/`（Windows 为 `%USERPROFILE%\.cursor-byok-v3`），再手动安装本版本。原上游应用不会自动切换到本 fork 的更新源。

This release uses this fork's signing key and GitHub update feed. Upstream installations require a manual switch. Future updates from this fork are verified with this fork's key.

## Validation and limits

- The source publication passed 279 server tests, formatting, Clippy, and frontend checks. Its Linux, Windows, macOS, and frontend CI jobs passed.
- Release preparation verifies the version manifests, frontend build, desktop debug build, updater helpers, and dependency audit. Published assets are built by the tagged release workflow.
- Automated protocol tests use synthetic requests and fake providers. This release does not claim that every Cursor version, model provider, or tool has been tested live.
- Linux packages require the platform libraries used by Tauri/WebKitGTK; RPM availability does not imply compatibility with every RPM-based distribution.
- Windows binaries do not have an Authenticode certificate. macOS applications are ad hoc signed and are not Apple-notarized. The updater signatures and SHA-256 checksums verify these release artifacts independently of operating-system publisher trust.

Please report reproducible problems in [this fork's Issues](https://github.com/bargino/cursor-byok/issues), with Cursor version, operating system, model protocol, and sanitized reproduction steps.
