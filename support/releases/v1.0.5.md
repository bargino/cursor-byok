# Cursor BYOK v1.0.5

## 图片生成

- 在 **Cursor 配置 → 添加模型** 中选择 **图片生成**，填写兼容 OpenAI Images API 的服务地址、API Key 和上游模型 ID。
- 在模型卡片上点击 **测试生图**，编辑提示词后点击 **生成测试图片**。每次请求生成一张图，成功后显示预览和耗时。费用由所选服务商决定。
- 在已打开的工作区中选择一个 BYOK 聊天模型，询问 Agent「我有哪些生图模型？」。指定显示名称即可选择模型，省略名称时使用排序最靠前的生图模型。确认生成后，Agent 会将图片保存到当前工作区。

## Changes since the last packaged release

- BYOK-managed Cursor Agent conversations can discover configured image models and use them through the OpenAI-compatible Images API. The desktop test dialog supports an editable prompt, preview, elapsed time, error feedback and cancellation. Batch chat tests skip image models.
- This release also includes the WorkBuddy, Qoder, TeleAgent and Kiro plugins previously distributed as 1.0.4 installer builds, together with account pooling, provider credit queries and concurrent account-storage fixes. [Provider requirements and validation scope](https://github.com/bargino/cursor-byok/blob/v1.0.5/support/releases/v1.0.4.md)
